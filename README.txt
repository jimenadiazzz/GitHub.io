# BLOOMÉ — sitio web

## Archivos
- `index.html`: estructura y contenido de la página.
- `styles.css`: colores, tipografías, distribución y diseño adaptable.
- `script.js`: menú desplegable para pantallas pequeñas.

## Cómo probarlo
1. Descarga y descomprime el ZIP.
2. Abre `index.html` en un navegador.
3. Comprueba los enlaces del menú, el botón de WhatsApp y la vista en computadora y celular.

## Cómo publicarlo con GitHub Pages
1. Crea un repositorio público llamado `TUUSUARIO.github.io`.
2. Sube los cuatro archivos a la raíz del repositorio.
3. En Settings → Pages, selecciona `Deploy from a branch`, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.

## Antes de entregar
Revisa que el número, Instagram, horario, precios y promoción sigan siendo correctos. Las fotografías se cargan desde Unsplash, por lo que requieren conexión a internet.
